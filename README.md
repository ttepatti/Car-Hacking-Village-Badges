## Relevancy Note

In the past (<2023), this repo existed to provide a centralized place to find all of the CHV SDKs, as they were spread out over a number of GitHub accounts, websites, etc. As of 2023+, the CHV has standardized uploading all of their firmware and badge-related files to their GitHub organization, [car-hacking-village](https://github.com/car-hacking-village). As such, this repo isn't really necessary now - check out the CHV GitHub for the latest firmware, repos, updates, etc.!

I'll keep updating this repo each year that I remember, but in general, you should be able to find the badge info on the main CHV GitHub now :smile:
